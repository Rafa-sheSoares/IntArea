## Descrição
    IntArea - Calculadora de Áreas entre Funções
        
        Uma solução web para cálculo de áreas de figuras geométricas formadas por gráficos de funções em um plano cartesiano.
        é inspirado em ferramentas como o GeoGebra, permitindo que estudantes e profissionais de áreas exatas solucionem problemas complexos de forma intuitiva e prática.
      

## Funcionalidades Principais
        Gráficos Personalizados
        Cálculo de Áreas
        Suporte a Múltiplas Funções
        Interface Intuitiva

       
## Exemplo Prático
        Função: f(x) = x^2
        Intervalo: [(0, 2]
        Resultado: Gráfico da parábola e a área entre o gráfico e o eixo X (≈ 2.67 unidades quadradas.)


## Instalação
        Clone o repositório:
            git clone https://gitlab.com/Rafa.she/calculo1-project.git
 
        Instale as dependências:
            npm install
                          
        Execute o projeto localmente:
            npm run dev

        Acesse em: 
            "http://localhost:5173" 

## Tecnologias 
    * Frontend: ReactJS, Recharts, TailwindCSS
    * Lógica de Cálculo: JavaScript para avaliação de expressões matemáticas e integração numérica.
    * Ferramentas de Build: Vite (para bundling) e PostCSS/Tailwind (para estilização).
